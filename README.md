# NFT Gift Monitor

Монитор конкретных Telegram NFT-подарков вида `ExampleGift-12345`.

Пользовательский Telegram-аккаунт и Telethon не нужны. Скрипт берет данные из публичной страницы `https://t.me/nft/<slug>`, а Telegram-бот используется для уведомлений и команд.

## Что отслеживается

- доступность страницы подарка;
- владелец, ссылка владельца, TON-адрес владельца;
- модель и редкость модели;
- фон и редкость фона;
- символ и редкость символа;
- название, коллекция, номер;
- картинка подарка, если включить `track_image_url`.

Изменения `кол-во`, `выпущено`, `исходный отправитель`, `исходный получатель` и аватар владельца не отправляются в бот. Они сохраняются в state/logs, но считаются тихими изменениями.

## Настройка

1. Создай отдельного Telegram-бота у BotFather.
2. Запусти `start.bat` один раз: он создаст `config.json`.
3. Заполни `bot.token`, `bot.admin_ids` и список подарков.

Пример:

```json
{
  "bot": {
    "token": "PUT_TELEGRAM_BOT_TOKEN_HERE",
    "admin_ids": [123456789]
  },
  "monitor": {
    "targets": [
      "ExampleGift-12345",
      "AnotherGift-67890"
    ],
    "interval_seconds": 30
  }
}
```

Можно вставлять и полную ссылку `https://t.me/nft/ExampleGift-12345`; скрипт сам возьмет slug.

## КД

По умолчанию `interval_seconds` равен `30`. Для малого числа подарков можно поставить меньше, например `10`, но если Telegram начнет отдавать `429` или `5xx`, скрипт включит backoff на `error_backoff_seconds`.

`request_delay_seconds` добавляет маленькую паузу между подарками внутри одного прохода. `jitter_seconds` добавляет случайную прибавку к паузе между циклами, чтобы запросы не выглядели идеально механическими.

`stale_error_notify_seconds` задает, когда отправлять ошибку в бот. По умолчанию это `3600`: одиночный `ConnectTimeout` не придет в Telegram, если следующий проход снова успешно обновит подарок. Ошибка отправится только когда конкретный подарок не обновлялся час.

## Команды бота

- `/status` - состояние мониторинга;
- `/gifts` - подарки из config и последние снимки;
- `/check` - проверить все подарки сейчас;
- `/check ExampleGift-12345` - проверить один подарок;
- `/snapshot ExampleGift-12345` - показать последний снимок из state.

## Файлы

- `state/nft_gift_state.json` - последний снимок каждого подарка;
- `logs/nft_gift_events.jsonl` - общая лента событий;
- `logs/gifts/<slug>/nft_gift_events.jsonl` - события отдельно по подарку;
- `logs/monitor.log` - технический лог.

## Важно

Telegram Bot API не дает метода “получить NFT-подарок по slug”. Поэтому монитор не запрашивает подарок “от имени бота” внутри Telegram API, а читает публичную web-страницу. Это все равно не требует пользовательской сессии и не спамит user-аккаунт.
